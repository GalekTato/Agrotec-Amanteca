\section*{Resumen ejecutivo}
\addcontentsline{toc}{section}{Resumen ejecutivo}
Agrotec-Amanteca presenta un sistema de apoyo a la decisión para estimar el rendimiento de parcelas de cebada en el contexto del Reto AgroCebada FIRA 2026. El sistema integra variables satelitales NDVI/EVI, precipitación CHIRPS, temperatura, topografía, superficie y contexto espacial. El conjunto oficial contiene 197 parcelas: 138 con rendimiento observado y 59 reservadas para predicción ciega.

El pipeline calcula índices agronómicos deterministas, selecciona 22 predictores mediante Smart-Pearson dentro de cada pliegue y agrega una variable IDW espacial calculada en UTM 14N. El modelo final es un ensamble ponderado de Extra Trees (40\%), Random Forest (25\%), SVR (20\%) y Gradient Boosting (15\%). La validación reporta MAE de 0.3562 t/ha, RMSE de 0.4968 t/ha y $R^2$ de 0.6124 en 5-Fold CV; en 5$\times$5 Repeated CV el RMSE fue 0.5073 t/ha. La cobertura empírica OOF del intervalo nominal de 80\% fue 81.2\%.

\begin{tcolorbox}[colback=agrogreen!7,colframe=agrogreen,title=\textbf{Interpretación responsable}]
Las métricas describen desempeño predictivo observado en las parcelas disponibles. El simulador representa sensibilidad del modelo ante entradas modificadas; no constituye un experimento causal ni una garantía universal para otras campañas o regiones.
\end{tcolorbox}

\section{Introducción}
El Reto AgroCebada FIRA 2026 solicita una solución analítica capaz de estimar el rendimiento de parcelas de cebada en Hidalgo, Tlaxcala y Puebla y convertirlo en una herramienta funcional de consulta. Agrotec-Amanteca responde a ese objetivo mediante un sistema que integra información satelital, climática, topográfica y geoespacial para producir una estimación por parcela. El problema es relevante porque el rendimiento agrícola depende de condiciones que cambian entre localidades y ciclos, mientras que las decisiones productivas y financieras requieren información espacialmente detallada y disponible antes de la cosecha.

El dataset oficial contiene 197 parcelas georreferenciadas: 138 con rendimiento observado, utilizadas para entrenar y validar, y 59 cuyo rendimiento fue reservado para evaluación. Por tanto, el proyecto no intenta reemplazar la medición de campo; construye una estimación reproducible para apoyar la priorización de parcelas, la interpretación de escenarios y la comunicación de riesgo. La solución combina un pipeline de ingeniería de datos con un ensamble de Extra Trees, Random Forest, SVR y Gradient Boosting.

Antes del entrenamiento se calculan índices agronómicos derivados de las series mensuales de NDVI/EVI, precipitación, temperatura, elevación, pendiente y superficie. La selección de variables se realiza dentro de los pliegues de validación para evitar que las etiquetas de validación influyan en el entrenamiento. El componente espacial IDW se calcula en coordenadas métricas UTM 14N y utiliza únicamente referencias permitidas en cada fold.

El resultado se publica como artefactos auditables, API FastAPI y dashboard web responsive disponible en GitHub Pages. La aplicación permite consultar el mapa, revisar predicciones, explorar incertidumbre y ejecutar escenarios de vigor satelital, precipitación y temperatura. La contribución principal es un flujo de extremo a extremo que conecta datos con una interfaz usable, manteniendo una interpretación honesta: las métricas son predictivas y observacionales, no una prueba de causalidad agronómica.

\section{Justificación}
Una predicción por parcela puede complementar la información de campo al identificar diferencias espaciales y comunicar el nivel de incertidumbre asociado. El proyecto se justifica porque combina variables que representan vigor vegetal, disponibilidad hídrica, régimen térmico y contexto físico con una aplicación consultable por personas no especialistas.

La selección y validación controladas reducen el riesgo de sobreajuste, mientras que la comparación contra un estimador nulo y un baseline permite medir si la complejidad añadida aporta valor real. La herramienta se plantea como apoyo a la decisión, no como sustituto de la experiencia del productor ni como garantía de rendimiento.

\section{Objetivos}
\textbf{Objetivo general.} Desarrollar y documentar un modelo analítico y una aplicación web funcional para estimar el rendimiento de cebada por parcela en el conjunto oficial del Reto AgroCebada FIRA 2026.

\textbf{Objetivos específicos.}
\begin{enumerate}
\item Integrar las variables oficiales y su referencia geoespacial.
\item Construir índices agronómicos deterministas.
\item Seleccionar predictores reduciendo redundancia y evitando fuga de información.
\item Comparar el ensamble con un baseline Random Forest y un DummyRegressor.
\item Cuantificar error mediante MAE, RMSE y $R^2$ con CV de cinco pliegues y repetición 5$\times$5.
\item Calibrar una banda de incertidumbre con cobertura empírica fuera de muestra.
\item Exportar predicciones para las 59 parcelas ciegas y ofrecer consulta cartográfica, simulación y descarga.
\item Explicar limitaciones para un uso responsable en contextos agrícolas y financieros.
\end{enumerate}

\section{Metodología}
\subsection{Datos e ingeniería geoespacial}
El universo se compone de 197 polígonos georreferenciados, con 138 etiquetas de rendimiento disponibles y 59 reservadas para predicción. Los polígonos se visualizan en WGS84 y sus centroides se calculan temporalmente en UTM Zona 14N (EPSG:32614), evitando medir distancias en grados. Las variables ambientales incluyen índices NDVI/EVI, precipitación CHIRPS, temperaturas máxima y mínima, elevación, pendiente y superficie. La extracción zonal documentada utiliza \code{all\_touched=True} para no descartar parcelas pequeñas.

\subsection{Variables y selección sin fuga}
A partir de las columnas originales se calculan cinco índices: área bajo la curva de NDVI, tasa vegetativa, caída de madurez, índice hidrotérmico y retención topográfica. El transformador \code{LeakFreeSmartPearsonIDW} ordena variables por correlación absoluta con el objetivo únicamente dentro del entrenamiento de cada fold, elimina redundancia con umbral 0.88 y conserva 22 variables; después agrega \code{spatial\_idw\_yield}.

El IDW usa las siete referencias más cercanas, potencia 1.5 y solo rendimientos del fold de entrenamiento, excluyendo coincidencias exactas. Así se evita que la etiqueta de una parcela de validación se incorpore directa o indirectamente a su predictor espacial.

\subsection{Modelado y evaluación}
El modelo final es un \textit{VotingRegressor} con Extra Trees 40\%, Random Forest 25\%, SVR 20\% y Gradient Boosting 15\%. Se comparan 11 configuraciones con KFold de cinco pliegues y RepeatedKFold 5$\times$5, usando MAE, RMSE y $R^2$. Las predicciones OOF se calculan para que cada parcela sea evaluada por un modelo que no vio su etiqueta.

La incertidumbre se calibra usando residuos OOF y una escala de dispersión del ensamble; la cobertura reportada es empírica. Finalmente, se ajusta el modelo con las etiquetas disponibles, se serializa en \code{joblib} y se sincronizan JSON, CSV, GeoJSON, dashboard y documento Word. El simulador modifica entradas, recalcula índices y evalúa escenarios combinados directamente con el modelo.

\section{Uso de la ciencia de datos en la inclusión financiera del sector agro}
La inclusión financiera requiere que productores y organizaciones puedan presentar información comprensible para planear inversiones, seguros, crédito y asistencia técnica. Un rendimiento estimado por parcela no constituye por sí mismo una autorización de crédito ni sustituye la evaluación financiera; sin embargo, puede servir como insumo operativo para ordenar visitas, comparar escenarios y discutir riesgos productivos con mayor evidencia.

El dashboard traduce variables técnicas a una consulta visual y exportable: cada parcela tiene una estimación, producción calculada según su superficie e intervalo de incertidumbre. Esto puede ayudar a que instituciones y técnicos identifiquen dónde hace falta información adicional antes de tomar una decisión, evitando tratar una predicción puntual como certeza.

El simulador permite explorar escenarios de clima y vigor, siempre con la advertencia de que son sensibilidades observacionales y no efectos causales. En una etapa posterior, el sistema podría integrarse con registros de manejo, costos, ingresos y siniestralidad para construir indicadores financieros más completos, con consentimiento y protección de datos. La propuesta contribuye a la inclusión financiera como herramienta de información y priorización, no como mecanismo automático de aprobación o rechazo de productores.

\section{Conclusiones}
Agrotec-Amanteca cumplió el objetivo de construir una solución funcional para estimar el rendimiento de cebada por parcela y consultar sus resultados en una interfaz web. La integración de datos satelitales, climáticos, topográficos y espaciales produjo un conjunto de 23 predictores consistente entre validación e inferencia. El ensamble superó al baseline y a la referencia nula bajo métricas medidas, y la validación OOF permitió reportar tanto error como cobertura empírica de incertidumbre.

La aplicación aporta valor porque conecta el resultado estadístico con un mapa, una tabla exportable y un simulador trazable. La conclusión no es que el modelo sea universal ni causal: su confiabilidad está condicionada por las 138 parcelas etiquetadas, la representatividad del dataset y la similitud entre futuras observaciones y el dominio de entrenamiento.

Para fortalecerlo se requieren nuevas parcelas independientes, campañas agrícolas adicionales y validaciones por localidad y tiempo. También debe mantenerse la separación entre predicción, simulación y decisión financiera. Bajo esas condiciones, el sistema es una base estable, lógica y auditable para apoyo a decisiones agrícolas, y cuenta con una ruta clara de mejora sin depender de añadir complejidad innecesaria.

\section{Respuestas a las preguntas guía del reto}
\begin{enumerate}
\item \textbf{¿Qué índice es más importante en la predicción?} La variable con mayor importancia relativa combinada en el artefacto auditado es \textbf{Potencial Microclimático Vecinal (IDW $k=7$)}, con \textbf{26.80\%}. No es un índice satelital: resume el contexto espacial de las parcelas de referencia y debe interpretarse como señal predictiva geográfica, no como causalidad. Entre los índices agronómicos sintéticos, el \textbf{Índice Hidrotérmico de Aridez (Prec/Tmax)} ocupa el primer lugar, con \textbf{10.70\%}.
\item \textbf{¿Qué variable climática tiene mayor peso?} Entre las variables climáticas individuales, \textbf{Temperatura Máxima 2023-02} alcanza \textbf{7.70\%} de importancia relativa combinada; le sigue \textbf{Precipitación 2025-02}, con \textbf{6.86\%}. Estas importancias son globales para este conjunto y método, no una ley universal ni un efecto causal.
\item \textbf{¿Qué combinación de variables funciona mejor?} La combinación ganadora es el conjunto de \textbf{23 predictores}: 22 variables Smart-Pearson más IDW, procesadas por el VotingRegressor de Extra Trees (40\%), Random Forest (25\%), SVR (20\%) y Gradient Boosting (15\%). Se seleccionó por su desempeño conjunto en 5-Fold y 5$\times$5 Repeated CV: RMSE 0.4968 y 0.5073 t/ha, respectivamente. No se afirma que una terna aislada sea óptima, porque el modelo aprende interacciones no lineales entre las 23 variables.
\end{enumerate}

\subsection{B. Declaración de uso de Inteligencia Artificial}
Durante el desarrollo se utilizaron herramientas de IA generativa como asistencia técnica para auditoría, programación asistida, pruebas, documentación y defensa oral. Se utilizó GitHub Copilot CLI para auditoría del pipeline, programación asistida, pruebas y documentación; Antigravity CLI se utilizó exclusivamente para correcciones y ajustes del diseño frontend. El equipo conserva la responsabilidad sobre la autoría, revisión, ejecución, interpretación y entrega.

\textbf{Prompts representativos utilizados:}
\begin{enumerate}[label=\textbf{IA-\arabic*:},leftmargin=2.4em]
\item Audita exhaustivamente el pipeline de Machine Learning e identifica riesgos de data leakage, especialmente en la selección de variables y el cálculo IDW dentro de la validación cruzada.
\item Comprueba si existe paridad entre las variables usadas en Cross-Validation, el modelo serializado y la inferencia de producción.
\item Revisa si el simulador evalúa escenarios combinados directamente con el modelo o si suma efectos marginales de forma incorrecta.
\item Revisa la API FastAPI, sus validaciones, sus advertencias deprecatorias y la cobertura de las pruebas automatizadas.
\item Revisa que el simulador y la curva fenológica reaccionen coherentemente a NDVI, precipitación y temperatura.
\item Compara las métricas del dashboard, README, artefactos y documento técnico para detectar números o afirmaciones inconsistentes.
\item Compara el reporte técnico del proyecto contra las bases oficiales del Reto AgroCebada FIRA 2026 e identifica entregables faltantes.
\item Prepara una guía de defensa oral con preguntas difíciles sobre fuga de datos, tamaño de muestra, causalidad, conformal e incertidumbre.
\end{enumerate}

Los prompts son representativos de instrucciones iterativas utilizadas durante el proceso. Las recomendaciones fueron revisadas por el equipo y los cambios se verificaron mediante pruebas, compilación o inspección directa. Las métricas fueron generadas por la ejecución del pipeline.
