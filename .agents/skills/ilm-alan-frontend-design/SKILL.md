# Frontend Design Skill (Ilm-Alan/frontend-design)

Eight anchors. Each is a distinct aesthetic territory locked to specific CSS tokens. Pick one per brief. Match its tokens.

> **Reach for the unexpected. Fidelity to the anchor. Discipline on the content. Nothing left to default.**

## 1. How to work
1. **Context** — Identify purpose, audience, domain, content density. State the problem in one sentence.
2. **Anchor** — Pick one. Lean unexpected. State the choice and the reason in one line.
3. **Differentiator** — Define one memorable anchor-internal move: a signature interaction, a typographic gesture, a layout motif, or a material treatment.
4. **System** — Match the chosen anchor's tokens exactly. Picking Swiss means white + sans + grid, not "some flavor of clean."
5. **Implementation** — Outline structure, then build. Content on screen is authored to the discipline in §2 — no fabrication, no filler, no themed replacement for standard UI copy.

## 2. Content is not design
- **No fabrication posing as real data.**
- **No filler labels** (`// INTELLIGENCE LAYER`, mono-caps subtitles nobody asked for).
- **No themed replacement of standard UI copy.**
- **No Unicode glyphs as icon substitutes.**
- **No AI-slop register.**

## 3. Anchor #1: Swiss (Selected for Agrotec-Amanteca FIRA 2026)
- **Surface:** Pure white `#FFFFFF` or neutral `#F7F7F8`.
- **Typography:** Akzidenz-Grotesk, Helvetica Neue, Söhne, or Inter — sans display and body, one family. Tabular numerals (`font-variant-numeric: tabular-nums`) as composition elements (folio numbers, section markers, condensed metrics).
- **Accent:** International Orange `#FF4F00` (or Swiss Red `#E4002B` / Yves Klein Blue `#002FA7`) — one primary signal accent, used deliberately.
- **Structure:** Visible grid lines or `1px` hairline rules (`#111111` / `#D4D4D8`). Left-aligned typography; asymmetric balance.
- **Breaks if:** warm paper, serif display, grain texture, rounded dark-slate AI-slop cards, or centered typography appears.
